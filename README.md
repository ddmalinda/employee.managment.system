# Spring Boot Employee Management System (ABC Company)

This is a complete **CRUD (Create, Read, Update, Delete) REST API** for managing employees, departments, and projects for **ABC Company Pvt Ltd**.

This project was built to demonstrate proficiency in **Spring Boot**, **Spring Data JPA**, **API design**, and **code quality analysis** using **SonarQube**.

---

## Features

✅ **Employee Management**: Full CRUD operations for employee records.

✅ **Department Management**: Full CRUD operations for departments.

✅ **Project Management**: Full CRUD operations for projects.

✅ **Relational Data**: Manages all entity relationships:
  - **One-to-Many**: A Department has many Employees.
  - **One-to-Many**: A Department manages many Projects.
  - **Many-to-Many**: An Employee can be assigned to many Projects.

✅ **API Documentation**: Interactive API documentation available via Swagger UI.

✅ **Code Quality**: Analyzed for bugs, vulnerabilities, and code smells with SonarQube.

✅ **Test Coverage**: Unit tests for the service layer with coverage reports generated by JaCoCo.

## How to Run the Application

### 1. Clone the Repository

```bash
git clone https://github.com/ddmalinda/employee.managment.system.git
cd employee.managment.system
```

### 2. Configure the Database

1. Open the `src/main/resources/application.properties` file.
2. Update the `spring.datasource.url`, `spring.datasource.username`, and `spring.datasource.password` properties to match your local MySQL configuration.
3. **You must manually create a database in MySQL.** (e.g., `CREATE DATABASE abc_company_db;`)

### 3. Run the Application

```bash
mvn spring-boot:run
```

The application will start on **http://localhost:8080**.

## API Endpoints

### 🧑‍💼 Employee Endpoints

**Base URL:** `/api/employees`

| Method | Endpoint | Description | Request Body | Response |
|--------|----------|-------------|--------------|----------|
| `GET` | `/api/employees` | Get all employees | - | `200 OK` - List of employees |
| `GET` | `/api/employees/{id}` | Get employee by ID | - | `200 OK` - Employee object<br>`404 Not Found` - Employee not found |
| `GET` | `/api/employees/department/{departmentId}` | Get all employees in a department | - | `200 OK` - List of employees |
| `POST` | `/api/employees` | Create a new employee | Employee JSON | `201 Created` - Created employee |
| `PUT` | `/api/employees/{id}` | Update an existing employee | Employee JSON | `200 OK` - Updated employee<br>`404 Not Found` - Employee not found |
| `DELETE` | `/api/employees/{id}` | Delete an employee | - | `204 No Content` - Successfully deleted<br>`404 Not Found` - Employee not found |

**Example - Create Employee:**
```json
POST /api/employees
{
  "firstName": "John",
  "lastName": "Doe",
  "email": "john.doe@company.com",
  "password": "securePassword123",
  "department": {
    "departmentID": 1
  }
}
```

### 📁 Project Endpoints

**Base URL:** `/api/projects`

| Method | Endpoint | Description | Request Body | Response |
|--------|----------|-------------|--------------|----------|
| `GET` | `/api/projects` | Get all projects | - | `200 OK` - List of projects |
| `GET` | `/api/projects/{id}` | Get project by ID | - | `200 OK` - Project object<br>`404 Not Found` - Project not found |
| `POST` | `/api/projects` | Create a new project | Project JSON | `201 Created` - Created project |
| `PUT` | `/api/projects/{id}` | Update an existing project | Project JSON | `200 OK` - Updated project<br>`404 Not Found` - Project not found |
| `DELETE` | `/api/projects/{id}` | Delete a project | - | `204 No Content` - Successfully deleted<br>`404 Not Found` - Project not found |
| `PUT` | `/api/projects/{projectId}/employees/{employeeId}` | Assign an employee to a project | - | `200 OK` - Updated project<br>`404 Not Found` - Project or Employee not found |
| `DELETE` | `/api/projects/{projectId}/employees/{employeeId}` | Remove an employee from a project | - | `200 OK` - Updated project<br>`404 Not Found` - Project or Employee not found |
| `GET` | `/api/projects/{projectId}/employees` | Get all employees assigned to a project | - | `200 OK` - Set of employees<br>`404 Not Found` - Project not found |

**Example - Create Project:**
```json
POST /api/projects
{
  "projectName": "Mobile App Development",
  "department": {
    "departmentID": 1
  }
}
```

**Example - Assign Employee to Project:**
```bash
PUT /api/projects/1/employees/1
```

## Testing & Code Quality (SonarQube)

This project is configured to run unit tests, generate coverage reports, and be scanned by SonarQube.

### 1. Run Unit Tests & Generate Coverage Report

This command runs all JUnit tests and uses JaCoCo to create a coverage report at `target/site/jacoco/jacoco.xml`.

```bash
mvn clean verify
```

### 2. Run SonarQube Analysis

Follow these steps to scan your local code.

#### Start SonarQube in Docker:

```bash
docker run -d --name sonarqube-server -p 9000:9000 sonarqube:latest
```

#### Log In & Get Token:

1. Wait 1-2 minutes for the server to start.
2. Open **http://localhost:9000** in your browser.
3. Log in with `admin` / `admin`.
4. Go to **My Account > Security** and **Generate a new Token**. Copy this token.

#### Run the Sonar Scan:

Execute the following command in your project's root folder, pasting your token.

```bash
mvn sonar:sonar \
  -Dsonar.host.url=http://localhost:9000 \
  -Dsonar.token=<PASTE_YOUR_SONAR_TOKEN_HERE>
```

#### View the Report:

Go back to **http://localhost:9000** and click on the **"Projects"** tab to see your full analysis.
